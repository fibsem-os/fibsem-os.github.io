# fibsemOS documentation

fibsemOS is control software for FIB-SEM microscopes, and AutoLamella is the
application built on it for automated cryo-lamella preparation. This guide
takes you from an empty computer to a running workflow, one page per task.

Every screenshot in this guide is taken from the application running against
its built-in simulator, so what you see here is what you will see on screen.
You can follow the whole guide on a laptop with no microscope attached.

## Start here

1. [Installation](/docs/installation): install fibsemOS and make a desktop
   shortcut.
2. [Getting started](/docs/getting-started): set up your microscope
   configuration and connect for the first time, with a worked example for a
   pre-tilted shuttle instrument (Aquilos, Hydra) and for the Arctis.

More pages are on their way: the sample holder, image acquisition, stage
movement, milling, fluorescence imaging, and the AutoLamella workflow. Until
they land, the [legacy walkthrough](/docs/walkthrough) covers the AutoLamella
workflow end to end.
